# TAP Cloud Infrastructure

Skill de arquitetura cloud. Não contém credenciais ou servidores em funcionamento. Prepare contas e autorização antes de provisionar.

Sugestão de stack, adaptável a restrições reais: GitHub + GitHub Actions (CI) + Cloud Run (backend) + PostgreSQL gerenciado e identidade gerenciada + Expo/EAS (mobile). Serviços exigem autenticação e podem gerar custos.
