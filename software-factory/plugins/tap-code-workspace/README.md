# TAP Code Workspace — v1.0.0

Plugin privado **skills-first**, integrado também ao pacote principal `tap-make-software` v2.0.0.

Skill e servidor MCP local para operações de workspace e verificações estáticas restritas. Não hospeda execução cloud; requer host desktop compatível e autorização de escrita.

**Autorização:** não concede ferramentas externas, hospedagem ou contas por si só.

**Uso:** `@tap-code-workspace <sua solicitação>`. A disponibilidade depende da ativação do plugin e da superfície do ChatGPT.
