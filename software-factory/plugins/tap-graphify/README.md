# TAP Graphify
Plugin privado de integração com o Graphify upstream, não uma cópia do motor. Para conectar o Graphify MCP oficial, habilite o plugin no ChatGPT e conclua OAuth quando disponibilizado. Repositórios precisam ser selecionados e indexados de forma autorizada.

O CLI `graphifyy` **não** está instalado por este pacote. Hooks automáticos são proibidos sem consentimento.

Upstream: https://github.com/Graphify-Labs/graphify
MCP oficial: https://github.com/Graphify-Labs/graphify-mcp
