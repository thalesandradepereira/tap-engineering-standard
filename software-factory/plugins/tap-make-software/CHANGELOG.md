# Changelog

## 2.0.0 — 2026-10-11
- Inclui cinco Skills especializadas embutidas e fluxo de configuração.
- Roteamento explícito e contrato de integração que não presume chamadas entre plugins.
- Plugins independentes compatíveis para invocação direta e runtime MCP local opcional (satélite).

## 1.0.0 — 2026-10-11
- Primeira versão, scaffolder PWA e 5 testes unitários.

## 4.0.0 — 2026-10-11

- Inclui 11ª Skill `tap-studio-runtime` e acesso a núcleo de projetos web self-hostable (arquivo, preview, sessão e API).
- Implementação real no plugin separado com CI e testes. Graphify e as outras Skills preservados.
- Dependências não prontas: host público, OAuth MCP, banco gerenciado, login social, QA E2E visual em navegador de teste, mobile build e limites de cobrança em provedor de LLM.
