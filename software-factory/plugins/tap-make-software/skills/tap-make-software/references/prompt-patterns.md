# Prompts / tarefas de alta precisão

## Start
“Construa [produto] para [público], com [3–6 fluxos], plataforma [web/PWA/mobile], preferências [UX], usuários [papéis], dados [entidades], integrações [nomes], publicação [alvo], orçamento [faixa]. Entregue PRD resumido, arquitetura, código executável, testes reais e limites.”

## Implementação incremental
“No repositório [repo], implemente [feature] sem modificar [escopo protegido]. Primeiro identifique testes existentes, contratos e causa raiz; depois crie testes de regressão e altere o menor conjunto de arquivos. Atualize README e mostre evidências do build.”

## Auditoria
“Revise [app] ponta a ponta, separando backend/frontend/dados/segurança. Para cada bug, informe reprodução, causa raiz, risco, patch, teste e estado verificado. Não declare testes que não executou.”

## Publicação
“Prepare [projeto] para [GitHub Pages/Cloud Run/host]. Faça preflight do ambiente, secrets, custos, banco e backup. Publique se a capacidade estiver conectada e autorizada; caso contrário entregue arquivos e comandos reproduzíveis sem inventar URLs.”

## Entrega final padronizada
1. Resultado gerado/alterado e o que existe concretamente.
2. Arquitetura e decisões com trade-offs.
3. Matriz de aceite e evidências.
4. Links e artefatos confirmados.
5. Limites e pendências reais.

Não prolongar perguntas se o usuário já forneceu restrições suficientes.
